# tau-memory

A zettelkasten for tau's runs (`docs/reference/plugins.md`, `tau-memory`):
one idea per Markdown note, with TOML front matter, linked and typed, in
`tau-memory/` in tau's folder for each repository, and in tau's data
folder for the person's notes across repositories. It also imports what
Claude Code and Codex learned on this computer (ADR 0044), as proposals
the person keeps or drops.

It was the Rust crates `tau-memory` and `tau-memory-host` until
2026-11-10 (ADR 0050, gap L).

- `src/plugin.luau`: the four tools (`memory_write`, `memory_search`,
  `memory_read`, `memory_link`), what a run starts with, the request
  before compaction drops a conversation, the pass after a run, stale
  marks from each turn's commit, its pages, `app`, setup step, settings,
  the import job and the actions its pages carry out.
- `src/memory.luau`: one scope's notes and their index; every write is
  checked, redacted and indexed here.
- `src/note.luau` and `src/toml.luau`: a note and its file.
- `src/store.luau`: the files, with every replaced version kept.
- `src/bm25.luau` and `src/recall.luau`: search, and one hop along links.
- `src/safety.luau`: secrets redacted, instructions refused.
- `src/render.luau`: what the model reads.
- `src/text.luau` and `src/unicode.luau`: words and white space as Rust
  read them; `unicode.luau` is generated by tau-built-in-tests.
- `src/import_read.luau` and `src/import.luau`: what Claude Code and
  Codex kept, read, and the proposals, checkpoint and job of an import.
- `src/ui_notes.luau`, `src/ui_import.luau` and `src/ui_settings.luau`:
  the notes pages, the review page, banner, menu entry and setup step,
  and the settings pane.
- `src/drawn.luau`: what the tests draw; only tests use it.
- `tests/demo.luau`: the fixture `demo`, what tau's demo shows of
  memory, made by the plugin's own functions.

`tau-plugin test plugins/tau-memory` runs its tests; `--bless` writes
its fixtures again.
